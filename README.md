# Yabi’s Fliesenwelt – Skill-Test „SideTwo-Standard“

Startseite für die Yabis Fliesenwelt GmbH (Duisburg-Rheinhausen), gebaut streng nach dem Skill
`handwerker-webseite`, Modus Entwurf: eine HTML-Datei, Schrift und Bilder eingebettet, keine externen Server.

Vorschau: https://bilal-altu.github.io/yabis-skilltest/ (noindex, robots.txt gesperrt)

## Bauen

```bash
node _quelle/bauen.mjs
```

Erzeugt `index.html` aus `_quelle/vorlage.html`. Bilder und Schrift kommen aus dem Nachbarordner
`../yabis/` (Repo Bilal-Altu/yabis-fliesenwelt) – `index.html` selbst ist eigenständig.

## Fehlt vom Kunden

- 3 Referenzfotos fertiger Kundenprojekte mit Ort und einem Satz
- Zahlen: Ausstellungsfläche (m²), Jahre Erfahrung, Zahl der Partner-Fliesenleger
- Anzahl Musterbäder bestätigen (Fotos zeigen drei)
- Orte, in denen Partnerbetriebe verlegen (Liste ist ein Vorschlag)
- Naturstein im Sortiment bestätigen, „Rückmeldung am nächsten Werktag“ bestätigen
- Richtige USt-IdNr. fürs Impressum
